## Product truth

- PC Web is a first-class Web target with the same Learning, Space, Statistics, Mine, membership, and audio meaning as the app targets.
- Learning remains one system-selected current card. The five interaction families retain different operation shapes, while hint and audio remain attached resources.
- Space remains `library -> group -> box -> card`; it is not a dashboard, favorites collection, or sleep-only collection.
- Formal Web purchase has equal product authority. Closed beta remains a separate read-only canonical access profile and cannot substitute for formal commerce.
- Shared continuity means daily progress, Space state, and entitlement reconciliation. Exact same-card cross-device resume is not promised.

## Implementation hypothesis

- The accepted `pcw-01` regions are mapping anchors, not component names or a DOM prescription.
- Existing `apps/web` behavior and tests are implementation context. They are not exact v5 evidence until a frozen browser replay records the row, environment, source/build identity, and evidence pointer.
- Remote Auth, canonical Learning/check-in/Space mutation, formal purchase/restore, receiver-managed access, and attached-audio playback remain blocked where the current implementation evidence declares them absent.
