# 软书四六级 · 卡片与空间

视觉基准服务于读题、操作、理解结果和连续学习。产品意图来自 `spec/product-core.json`；学科身份、两档自评、物理层级来自 `spec/visual-language.json`。表现手段可按 `spec/machine-acceptance.json#harness_strategy.experience_acceptance` 修订。

## 当前基准

- 一张纸面承载一个学习任务。字号、字重、间距区分题目、材料、操作、帮助与结果。
- 题材来自正面；解析与背面不能被转换器填到正面。重复文本只显示一次。
- 答错首层先给正确答案与用户选择，再解释关键原因；详细解析按需展开。
- 翻面前后有信息增量；四选一选项可比；开锁让句子逐步成形；消除直接作用于可唯一定位的原句成分；左右判断只有一个可拖动对象。
- 收藏与待复习作为跨卡盒的筛选视图，结果显示所属书架、分区和卡盒，点开回到原盒，不改变学习顺序或归属。只筛选当前有权访问的卡片。
- 当前盒与相邻盒同时可见。书架、分区、盒、卡片用包含、位置和尺度表达，标签用于辨认。
- 帮助附着在当前卡，先通过一个“需要帮助”入口展开；打开入口不记为使用提示。`peek` 与 `hint` 分别按实际打开内容保留事件，收藏是卡片标签，休眠仍在原盒归属下。
- 长题干降低字号与字重，正面材料保持完整；长选项根据内容、可用宽度和系统字号变成单列。听力入口紧跟问题和材料，先读选项的题仍先显示题目说明，不自动播放。
- 手机外部卡片与行动位置稳定。内容长度决定内部布局与滚动，不为短内容填充说明或设半屏占比。
- 导航轻于学习动作；正常同步、已登录和没有音频不作为常驻提示占用注意力。

统计分别展示今日完成、待复习与有完整记录支持的累计数量，不把卡库总量或“已完成加待复习”当作今日目标。登录、统计和我的减少重复标题与层层卡片；正常保存状态保持安静。

## 身份与反馈

| 学科 | 身份色 |
|---|---|
| 听力 | #5B6DF5 |
| 阅读 | #FF8A3D |
| 选词填空 | #22C58B |
| 写作 | #B568F5 |
| 翻译 | #18C4E0 |
| 词汇 | #F15B6E |
| 语法 | #F5B100 |

身份映射跨端稳定，当前学科拥有一个主强调色；其他学科在空间中只作小面积标识。品牌、身份和结果有各自范围，不靠颜色单独传达含义。

翻面自评只有两档：有把握（mint，#22C58B）/ 需要复习（amber，#F5B100）。自动判定不要求用户再做掌握度自评。

## 共同表现

采用 B「轻快」：浅紫灰背景（#F0F0F8）、白色纸面（#FEFEFF）、24px 卡片圆角、14px 操作圆角、轻量章节色条。浮动导航和登录面板使用克制的阴影。圆角与描边只用于真正独立的对象；说明段落和结果对照用留白组织。玻璃、grain 和背景光斑均非质量门槛。

手机题目约 20px/600，正文约 15px/400，辅助信息约 12–14px；实际内容、屏幕宽度与系统字号优先于固定数值。主操作可触达，文字不裁掉，减少动态效果保留全部操作。

动效遵循 `interaction-motion/light-studio-motion-v1.md`：按压、选择、揭示、翻面、换卡、空间层级和播放状态各自表达实际反馈，后台与减少动态效果设置停止装饰循环。

## 审查

Q1 学科色是否正确且只作当前强调；Q2 首读对象与次级信息是否清楚；Q3 动作是否改变真正的学习对象；Q4 是否引入无关装饰或奖励负担；Q5 材料、操作和安全区是否可用；Q6 是否保持两档自评及系统顺序学习。

这些问题必须结合实际页面与操作回答，不能把引用本文件当成通过结论。
