## Decision

Adopt Daylight Studio as the first accepted complete mobile visual baseline. Stable violet identifies Softbook. The proof's generic `当前馆` is explicitly bound to canonical hall index 1 and therefore uses that index's canonical coral identity; coral is not a movable “current” color. Other hall dots preserve the canonical seven-hue order. Production copy must resolve canonical names from the knowledge-map owner rather than ship the proof placeholders. White carries the task. Semantic green, mint, and amber keep correctness and flip assessment independent from brand and hall identity.

## Non-negotiable carry-forward

One task, one primary action; no internal language leakage; no horizontal overflow; no dashboard-first Statistics; no browse-first Learning; no collapsing the Space hierarchy; no four-level assessment; no red “再回看”; no implementation redesign in code.

## Re-entry rule

Any material change to palette roles, app silhouette, navigation composition, core interaction silhouette, or Space containment requires a new design-only artifact and review before implementation.
