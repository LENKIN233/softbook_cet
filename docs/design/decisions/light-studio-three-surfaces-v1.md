# 三端轻快风格 v1

## 决定来源与范围

用户从同会话三版 HTML 中选择 B「轻快」，随后要求按该风格重构三端并配置丰富、合理、合适的动画。本决定是 iOS、Android、Web 的共同表现基准，替代旧基准中的暖灰底色、较重字重和密集边框。产品语义仍由 `spec/product-core.json`、`spec/interactions.json`、`spec/space-operations.json` 负责。

渲染参考：`docs/design/visual-reference.html`。示例文字只说明视觉结构，不是运行卡库。真实内容来自现有导入链。

## 共同语法

- 浅紫灰背景，白色纸面；品牌紫只用于全局导航。学习和空间由当前学科的稳定身份色主导。
- 卡片 24、区域 20、操作 14、浮动导航 22 的圆角；手机侧边距 18，宽屏 28。以文字层级和间距组织内容。
- 章节色条在纸面上方，呈现课程、书架、分区、卡盒、真实进度和收藏。短内容自然收拢；长材料完整保留并滚动，动作区始终可达。
- 问题默认 20/600，正文 15/400，说明 13，标题 24。长题与系统大字号优先于默认尺度；禁止裁去题目、选项和解析。
- 手机胶囊导航、平板侧栏、Web 窄轨均使用学习／空间／统计／我的。登录、验证、退出、错误和空态沿用同一控件语言。
- Web 宽屏可在卡片旁显示安静的所属卡盒信息；窄窗移除该信息栏。上下文不得成为第二个学习任务。
- 四选一短选项使用两列，选项字母和文本形成层级；长选项、窄屏或大字号改成单列。其他四种交互保留独立轮廓与判定语义。
- 我的页按内容高度滚动，底部注销与退出入口保持可达；收藏与休眠成功以对象自身状态反馈，失败与恢复通知保留。
- 统计展示真实今日、待复习和累计记录；不添加虚构目标、进度曲线或奖励。

## 空间表现

沿用 `docs/design/physical-space/space-model-v1.md` 的书架→分区→卡盒→卡片关系。书架保留身份色点，书架与分区的选择器使用可辨认的勾选和选中背景；卡盒采用顶部身份色的文件夹形块。打开的盒子显示所属位置和卡片；当前浏览卡完整展示，缩略卡允许摘要并可展开。浏览、收藏、休眠不能改变系统学习顺序或卡片归属。

## 验收边界

以运行页面确认层级、完整材料、操作可达、安全区、播放及错误恢复；以连续操作检查中断、重复提交和减少动态效果。捕获绑定当前源码及运行环境。原生模拟器、Web 浏览器、单元测试和正式发布证据分别记录，参考图与作者说明不能证明体验通过。

- 短窗口允许整页纵向滚动，为材料与选项保留阅读空间。原生页面按章节栏和动作区的实际高度分配空间；换卡、翻面和显示反馈时回到阅读开头，旋转保留学习组件和作答状态。
- 学习快捷键只响应无修饰键、未在输入法组字中的单次输入，不抢占浏览器组合键或可编辑控件。
- 原生导航和章节信息最多随系统放大至1.5倍，星形图标保持尺寸。题干、选项、答案和解析完整响应辅助字号，并可滚动阅读；选项字母徽标随字形增长，不能固定高度裁掉字母。

## 2026-09-26 文案与预览修订

用户指出预览顶部的米黄色调试条以及题干的指令口吻。原生本地后端入口移除常驻调试条，重新从运行程序采集截图和录屏。Web 页眉删除空泛的鼓励句，侧栏只保留“卡片位置”和打开卡盒的动作。加载过程只显示一处“正在加载卡片…”，保留失败时的重试和更新入口。换卡时尚未载入的新会话同样显示加载提示，不误报为全部卡片休眠。相关表达遵循 `docs/design/canon.md#文案`。

同级 card make 工作区审查并修订四、六级72张听前预测卡的正面表达，再通过正式导出工具消费。导出器的解析标题不再取内部 main_training_goal；保留明确作者标题，缺省使用“解析”。不从答案重造正面，也不改动原有学习判定。

## 2026-09-27 登录恢复修订

同一手机号并发首次登录时，另一端完成注册会使旧验证码上下文失效。客户端明确提示重新获取验证码，Web 返回入口同时标明可重新获取；保留原手机号并清空旧验证码后走原有申请流程。保持服务端账号代次校验与限流，不重试绑定到新账号的旧验证码。

原生失效状态的辅助标记使用“需重新获取”，避免“可重试”暗示旧验证码仍有效。验证码阶段的所有错误提示均保留与登录按钮的间距。

验证码数字键盘可能遮住底部登录按钮。原生验证码输入聚焦时，在“更换手机号”旁显示明确的“收起键盘”操作；它只收起键盘，不提交验证码，触控区域至少 44 点。键盘收起后仍由原有“登录”按钮提交。iOS 键盘辅助工具栏可以保留，但不能成为唯一的收起入口。

## 2026-09-28 阅读质量修订

在真实四级首卡与窄屏实拍中，连续中文提示词会把“排放”拆到两行。保留题干、字号与卡片来源，在 Web 正面材料上优先按中文词组换行，在 Android 紧凑学习视口按列举项与问句边界断行；不能为了修复一个词而把“什么话题”等其他词拆开，也不能引入横向溢出或裁切。浅紫章节条上的小字使用现有的次级正文色，保证稳定页面达到普通小字的对比度要求。以实际 Web、Android、iOS 页面和作答路径复验。

## 2026-09-28 品牌入口图标

启动图标沿用现有 `StudioMark` 的打开书本轮廓，以深墨色纸面和白色线条构成单一剪影；不加入学科身份色或额外文案。`apps/web/public/favicon.svg` 是矢量源，iOS 的不透明 AppIcon、Android 的传统与自适应图标、Web favicon 和加入主屏图标由同一轮廓派生。系统桌面的应用名称统一使用“软书四六级”，Android 系统栏与 Web 浏览器主题色贴合浅紫灰页面。实拍需确认缩小后仍能辨认书本、暗色与圆形遮罩不裁掉线条；应用内四入口和学习交互保持原样。


## 2026-09-30 运行评审后的产品修订

- 统计跟随当前四级/六级。主层显示“今天练过 N 张卡”，附“共完成 M 次练习，含 R 次复习”；卡片去重、作答计次。累计学过独立显示；缺失当前科目统计时说明暂不可读，不拿旧账号总数或最新单卡结果补零。账号签到保持独立口径，复习入口降为次级。
- 空间先呈现紧凑地址、当前盒与正在学习的卡；“浏览全部卡盒”按需展开，仍可访问完整层级及原盒内休眠区。浏览别盒与返回学习保留作答状态。
- 判断方法一次展开即给实际内容；核对答案与具体依据相邻，原题及选项按需回看。完整解析去除重复自评和题型大标题。
- CET4 首段以稳定的 000001–000005 五张卡练习比较对象、线索和推断边界，内容由 card make 导出。五张是当前作者编排，不是所有学习路径的固定节拍。音频、自评和客观判分的边界不变。
- 普通服务端学习提供“返回”和基于本次确认结果的记录；首段从未完成到五张均完成时给一次页内小结，完成一组后的收尾按钮使用“先到这里”。历史已完成、重复确认、未提交答案不能伪造本次完成。返回保留原卡，继续仍服从服务端调度；未经保存确认不写“进度已保存”。

上述修订取代本文件早期层级和控件表现描述中的相应部分；所有题材内容与统计事实仍服从领域 owner。以 Web、iOS、Android 的实际作答、空间往返和当前科目记录验收，不以文案或样式拼写作为产品判断。

## 2026-10-03 操作入口修订

针对用户指出的图标缺失和文字切换不显眼，三端操作采用共享图标几何，交互控件基准由 `spec/visual-language.json` 的 component vocabulary 维护。课程按钮直接展开四、六级选择，个人账号使用独立入口；“我的”仍可切换科目。返回、帮助、展开、收藏、休眠、复习和登录辅助沿用真实动作与状态，重要操作不再借助字体箭头或星号表示。

运行比较发现的窄点击区域、选中标记挤断科目名称及动态字号裁切均按实际布局修正。字号变化只调整文字呈现，学习材料、未提交选择、学习记录、音频和原有账号确认流程保持各自的行为语义。
