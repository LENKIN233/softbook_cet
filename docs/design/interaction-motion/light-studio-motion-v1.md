# 轻快风格动效 v1

共同数值来自 `apps/mobile/src/visual/studio.ts`；Web 直接导入并转成 CSS 变量。表达相同，执行依平台能力适配：原生使用 native driver，Web 使用 CSS / Web Animations / View Transitions。

| 场景 | 表达 | 时间与触发 |
|---|---|---|
| 按压 | 控件压至 0.98 后回弹；点击行为不等动画 | Web 按下 100ms、释放 180ms；原生阻尼弹簧 320/27/0.8 |
| 选中、收藏、导航 | 背景色和局部轻缩放明确当前状态 | 180–240ms，只有状态变化触发 |
| 翻面 | 同一对象离场转至侧面，再进入背面 | 140ms + 180ms |
| 下一张 | 旧卡向左离开，新卡自右进入 | 140ms + 240ms |
| 帮助、解析、统计值 | 小幅 4–8px 位移与透明度变化 | 220–240ms，实际内容改变时 |
| 开锁 | 锁扣向上转开，形成的句子保留 | 220ms，正确锁位发生变化时 |
| 消除 | 原句成分划线、恢复；正文位置保持稳定 | 160ms，可撤回 |
| 左右判断 | 顶层对象随方向离场 | 220ms，保留按钮与键盘等价入口 |
| 空间层级与路由 | 当前对象与卡盒保持连续，轻缩放与淡入 | 页面约 300ms，盒内 240ms |
| 音频播放 | 播放控件变暂停，波形轻呼吸 | 半周期 900ms，只在实际 playing 状态循环 |

音频波形只表示播放状态，不冒充声波采样、进度或时长；旁边的录音秒数来自音频资源。暂停、结束、失败、离开页面和减少动态效果均停止循环。

动画不拥有判分与事件：快速连点只能提交一次，失败恢复可操作卡片，身份变化和卸载取消旧动作，减少动态效果中途切换只完成尚未提交的意图一次。空间路由提交前保持旧页退出状态，新页面负责入场。

减少动态效果时移除空间位移、翻转、弹簧和循环，直接显示最终状态。无 View Transitions 支持的浏览器直接切页，保留局部反馈。不得用庆祝、背景漂浮或自动播放争夺读题注意力。
