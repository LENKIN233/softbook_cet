# Mobile Daylight Studio Motion V1

## Principles

Motion confirms a state transition; it never advertises the interface. Default duration is 180–320 ms with ease-out. Reduced-motion removes transformation and leaves immediate opacity/state changes.

## Learning

- option selection: border/fill changes in 180 ms; no bounce;
- submission: inline result expands below options and moves the same primary action to continuation;
- flip: front/back content crossfades after explicit reveal; no 3D novelty rotation;
- audio: only a user press starts playback; loading, playing, paused, error, and retry share one state source;
- assessment: exactly mint “有把握” and amber “再回看”; selection advances the system sequence.

## Lock, elimination, swipe

- lock: a row settles only after a successful user action; partial correction remains visible;
- elimination: reversible strike appears on the selected phrase, then result distinguishes chosen and required fragments;
- swipe: drag follows the pointer, threshold preview appears before commit, cancel returns to center, and buttons/keyboard provide equivalent actions.

## Space continuity

Learning → Space reveals the same card inside the active box; Space → Learning returns to the preserved task/result. Favorite changes the card tag. Sleep moves state within the current box and must expose pending/error/retry in implementation.

## Sheets and navigation

Bottom sheets rise from the safe-area edge with backdrop fade. Route transitions use a short vertical fade and restore focus to the destination heading. No ambient or looping decorative motion is allowed.
