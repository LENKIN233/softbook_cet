# Learning Interaction Evolution Failure Sedimentation v1

## Product Truth

Stable card identity is not permission to render a giant fixed white slab. Progressive disclosure is not permission to hide required actions behind gestures.

## Rejected Patterns

### Giant White Slab

A fixed near-full-height opaque card with compact content leaves unused white area as the dominant visual object. Correction: keep a stable atmospheric stage and let the material content sheet size intrinsically inside it.

### Multiple Disclosure Controls

Showing peek, hint, location, and other helpers as peer controls competes with the task. Correction: use one contextual edge disclosure slot while preserving distinct semantic callbacks and accessibility labels.

### Gesture-Only Quietness

Hiding support and favorite behind long press, tilt, or edge gestures reduces visible noise but violates discoverability and assistive access. Correction: keep visually lightweight explicit targets with 44pt/48dp hit regions.

### Permanent Card Stack

A visible stack in every focus state teaches swipe movement even for non-swipe interactions. Correction: show a shallow next-card edge only during settle/continue.

### Separate Result Report

Moving correctness and explanation to a new report page breaks the current object's continuity. Correction: resolve and explain inside the same material sheet; optional deep detail remains secondary.

## Reuse Rule

Future Learning changes must reject these patterns unless a later completed design search proves a version that beats Quiet Object Theatre without weakening single-card primacy, five interaction silhouettes, or accessibility.
