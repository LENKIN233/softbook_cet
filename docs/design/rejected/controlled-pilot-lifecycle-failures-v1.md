# Controlled Pilot Lifecycle Rejected Failures v1

## Source

`docs/design/search-runs/2026-08-01-controlled-pilot-lifecycle/`

## Blocking Start Modal

Rejected because it displaces the first valid card, creates acknowledgement work, and makes trial start semantics ambiguous.

## Countdown or Lifecycle Dashboard

Rejected because it centers time and counters, implies client authority, and increases anxiety without helping the next card.

## Equal-Weight Completion Menu

Rejected because review, Space, and continue cannot be three equal primary choices. Continue remains dominant; review and Space are quiet alternatives.

## Tutorial Carousel

Rejected because Space value should be learned through the completed card’s actual location, not pre-explained through generic pages.

## Payment-Like Receipt

Rejected fragments include currency, totals, checkout language, perforated coupons, premium badges, and self-service grant controls. The accepted compact receipt communicates confirmed placement only.

## Track Catalogue or Disabled Entry

Rejected because the controlled pilot has a fixed identity. No unavailable track teaser, selector, or upsell appears.
