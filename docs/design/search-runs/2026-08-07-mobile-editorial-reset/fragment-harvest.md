# Fragment Harvest

## Best Focal Object

`mue-01`'s tall paper object with a coral library margin rail. It fills the working viewport and carries content, tools, and primary action without turning into a feed.

## Best First-Read Path

`mue-01`: route/progress → question → exam explanation → attached flip edge → quiet navigation.

## Best State Language

`mue-01` keeps front/back as two sides of the same object; `mue-03` contributes compact auto-score answer rows that do not ask for mastery judgment.

## Best Space Or Interaction Model

`mue-02` contributes the nested-card depth cue. The promoted Space synthesis converts that cue into a real box with visible sibling compartments and a current-card marker.

## Best Platform Adaptation

The margin rail can become a left-side spine on phone, a persistent card gutter on tablet, and a narrow current-object rail on PC web without duplicating navigation or content.

## Rejected Failure Patterns

Glass as product personality; giant active navigation pills; tiny focal cards; ambient empty areas; dashboard resume cards; full-screen accent fills; visible learning timelines.

## Synthesis Inputs

`mue-01` supplies the object and hierarchy, `mue-02` supplies spatial compartment depth, and `mue-03` supplies compact answer rhythm. The synthesis is rendered in `docs/design/mocks/mobile-editorial-study-object-v2.html`.
