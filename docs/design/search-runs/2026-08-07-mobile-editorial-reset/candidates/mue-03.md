# Efficient Answer Rail

## Candidate ID

mue-03

## Provenance

- Tool or model: Codex design synthesis
- Prompt: Build a fast phone answer surface using deep plum, editorial cream, and compact option rails without dashboard chrome.
- Source context pack: `context-pack.md`
- Artifact: `candidate-proofs/mobile-editorial-candidates.html#mue-03`
- Screenshots: `candidate-proofs/mobile-editorial-candidates.html#mue-03`

## Product Truth Fit

Keeps one current CET question and makes the primary auto-scored decision fast and obvious.

## Focal Object

A cream answer sheet suspended in a deep-plum page environment.

## First-Read Path

Question → insight → answer rows → quiet navigation.

## Interaction Silhouette

Auto-scored option rail; it is intentionally not promoted as the universal interaction silhouette.

## Spatial Model

Library and box appear in the sheet header, while Space remains a route rather than visible compartments.

## State Language

Coral-soft fill marks a current selection; correction waits until submission.

## Motion Causality

Rows settle on selection and the answer sheet advances vertically after submission; reduced motion changes state without travel.

## Platform Strategy

Phone uses a single sheet. Tablet could place explanation beside the answer rail.

## Implementation Mapping

Maps cleanly to multiple-choice or lock rows but requires distinct branches for flip, elimination, and swipe.

## Known Risks

The dark surround can feel heavy over long sessions and answer rows can homogenize interaction silhouettes.

## Design Review Checklist Answers

Q1: The current active subject uses coral as the only strong accent.

Q2: The answer sheet is focal and the task path is direct.

Q3: The rendered state is an auto-scored option surface, not a flip card.

Q4: No forbidden patterns appear; deep plum replaces pure black.

Q5: The 393 × 852 frame is contained and keeps navigation clear.

Q6: There is no self-assess on this auto-scored state and no module picker.
