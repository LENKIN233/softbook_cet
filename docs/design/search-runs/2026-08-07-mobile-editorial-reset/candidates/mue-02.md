# Physical Index Stack

## Candidate ID

mue-02

## Provenance

- Tool or model: Codex design synthesis
- Prompt: Make the current CET card feel physically indexed in a box while preserving a 2×2 multiple-choice silhouette.
- Source context pack: `context-pack.md`
- Artifact: `candidate-proofs/mobile-editorial-candidates.html#mue-02`
- Screenshots: `candidate-proofs/mobile-editorial-candidates.html#mue-02`

## Product Truth Fit

Preserves current-card focus and visually connects Learning to a physical box through layered index cards.

## Focal Object

The front index card, with two shallow sibling-card edges behind it.

## First-Read Path

Question → 2×2 options → confirm → box tab → navigation.

## Interaction Silhouette

Canonical multiple-choice prompt with a 2×2 option grid.

## Spatial Model

Depth implies nearby cards inside the same box; the top tab names the current library and box.

## State Language

Coral rim indicates selection, while correctness appears only after confirmation.

## Motion Causality

Selection settles in place; completion moves the front card behind the stack. Reduced motion swaps z-order instantly.

## Platform Strategy

Phone shows two shallow layers; tablet exposes more of the box without turning it into a carousel.

## Implementation Mapping

Maps to the multiple-choice branch, current-card transform stack, and Space box address.

## Known Risks

Decorative layers can compete with content and make other interaction types look incorrectly card-stack shaped.

## Design Review Checklist Answers

Q1: The current active subject uses coral alone for the tab and selected rim.

Q2: The front card and question are focal; options then confirm are the task path.

Q3: The 2×2 multiple-choice silhouette is preserved.

Q4: The proof avoids forbidden patterns and uses no correctness color before submit.

Q5: The 393 × 852 stack remains contained above the navigation.

Q6: Learning remains system-sequenced; the candidate is auto-scored and does not show self-assess.
