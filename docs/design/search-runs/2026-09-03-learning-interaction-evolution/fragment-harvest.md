# Learning Interaction Fragment Harvest

## Best Focal Object

`lie-08` makes the current card a stable stage while the exam sheet becomes the dense, readable surface. This avoids both a generic page and an oversized empty slab.

## Best First-Read Path

`lie-02` contributes the clean path: prompt -> interaction -> anchored primary action. Address, favorite, and support stay outside that path until needed.

## Best State Language

`lie-08` keeps support conditional and replaces the task sheet with correctness/analysis in place. Bookkeeping appears only as a quiet line near continuation.

## Best Space Or Interaction Model

`lie-04` contributes a shallow rear edge that implies the next physical card, but the top card must not move sideways except for the dedicated swipe interaction.

## Best Platform Adaptation

`lie-08` retains touch-sized invisible hit regions on phone, widens the sheet on tablet, and switches to compact pointer targets plus focus/hover states on PC-Web.

## Rejected Failure Patterns

Do not preserve the baseline giant white slab, surround the card with a control halo, hide support behind gestures, or turn analysis into a separate report page.

## Synthesis Inputs

Promote a mutated `lie-08`: stable accent stage, compact material sheet, one contextual disclosure slot, one reusable action rail, optional shallow next-card edge, and in-object task-to-analysis transition.
