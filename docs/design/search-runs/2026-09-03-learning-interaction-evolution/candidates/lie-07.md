# Learning Interaction Candidate

## Candidate ID

lie-07

## Provenance

- Tool or model: model:codex
- Prompt: Show prompt, hint, explanation preview, progress details, confidence, and next-card preview in one workbook screen.
- Source context pack: `docs/design/search-runs/2026-09-03-learning-interaction-evolution/context-pack.md`
- Artifact: No-render rationale: hard-filtered as a dense poster rather than an operable single-card flow.
- Screenshots: No-render rationale: information architecture fails before visual rendering.

## Product Truth Fit

Maximizes information visibility while directly violating low operation burden and staged feedback.

## Focal Object

No single focal object; several panels compete.

## First-Read Path

Prompt -> hint -> preview -> options -> metrics -> continuation.

## Interaction Silhouette

The five interactions become small widgets inside a workbook page.

## Spatial Model

Space and progress turn into mini dashboards.

## State Language

System explanation appears before user action.

## Motion Causality

Panel-level expansions produce layout motion unrelated to the card action.

## Platform Strategy

Requires scrolling even for short cards and becomes denser on desktop.

## Implementation Mapping

Would split the single object into many peer components.

## Known Risks

Cognitive overload and loss of the primary learning path.

## Design Review Checklist Answers

Q1: Multiple panels compete despite one hue.
Q2: First-read path is ambiguous.
Q3: Canonical silhouettes are miniaturized.
Q4: Dashboard density violates the single-card contract.
Q5: Phone containment requires document scrolling.
Q6: Learning becomes a management surface.
