## Product Truth Fit

Strongly communicates sequence and physicality without asking the learner to choose a module.

## Focal Object

The top card in a shallow stack.

## First-Read Path

Top card -> task affordance -> edge support -> next card reveal.

## Interaction Silhouette

The top card contains the five canonical task shapes; the stack remains background only.

## Spatial Model

The rear card edge implies continuity, not arbitrary browsing.

## State Language

Result settles onto the top card before it leaves the stack.

## Motion Causality

Completion moves the top card a short distance and exposes the next card; cancelled interactions return to center.

## Platform Strategy

Phone benefits most; desktop risks decorative empty depth unless the stack remains shallow.

## Implementation Mapping

Requires one background stack layer plus existing task and result planes.

## Known Risks

May imply swipe navigation for every interaction and compete with the dedicated swipe interaction.

## Design Review Checklist Answers

Q1: Only the top card uses the current-library accent.
Q2: The current top card is unmistakably focal.
Q3: Internal silhouettes remain, but the outer stack risks over-signaling swipe.
Q4: No forbidden reward or gradient treatment is used.
Q5: The shallow stack remains within the phone safe area.
Q6: Flip remains two-state; stack movement never becomes mastery scoring.
