## Product Truth Fit

Preserves the addressed physical card while separating stable spatial identity from the content sheet's intrinsic density.

## Focal Object

One current card stage containing a compact exam sheet and an anchored action rail.

## First-Read Path

Prompt sheet -> interaction silhouette -> primary action -> in-place result; address and tag remain peripheral.

## Interaction Silhouette

Flip, choice grid, lock rows, strike set, and swipe deck each own the sheet body; the surrounding stage does not change their shape.

## Spatial Model

The card's accent spine and stage remain fixed. Favorite is a quiet tag glyph. Peek is the lightweight address aperture; hint alone uses the attached edge disclosure slot when authored content exists.

## State Language

Support appears only after request. Correctness and analysis replace the task body in place, then settle into one continuation action.

## Motion Causality

Press state compresses the chosen object; resolve morphs the same sheet rather than navigating away; completion advances the card with a short directional settle. Every motion is interruptible and has a fade-only fallback.

## Platform Strategy

Phone uses one vertical stage. Tablet widens the sheet and keeps actions close. PC-Web adds keyboard/focus states without scaling touch buttons to desktop size.

## Implementation Mapping

Existing Learning current-object container becomes the stable stage; prompt/support/interaction/result become one sheet state; the bottom submit and next actions become one reusable action rail.

## Known Risks

The address aperture must keep a full invisible hit region without visually becoming another pill button.
