## Product Truth Fit

Keeps one current card and one primary action while converting blank card area into a lightly tinted material stage.

## Focal Object

An opaque exam sheet floating on a stable tinted stage.

## First-Read Path

Address rail -> exam sheet -> interaction -> anchored action shelf.

## Interaction Silhouette

The task sheet changes internally for flip, grid, rows, strike set, or swipe deck.

## Spatial Model

Address is a thin spine; favorite is a small tag on that spine.

## State Language

Prompt and result remain exam-facing; bookkeeping appears as a short line near the action shelf.

## Motion Causality

The sheet crossfades or folds to analysis while the stage and action shelf remain fixed.

## Platform Strategy

Phone uses one centered sheet; tablet and desktop can widen the sheet without adding dashboard panels.

## Implementation Mapping

Map stage, sheet scroll, and action shelf to the existing Learning surface and interaction bodies.

## Known Risks

Could feel like a generic exam worksheet and weaken the physical card metaphor.

## Design Review Checklist Answers

Q1: One current-library edge owns the accent.
Q2: The exam sheet is the first-read object.
Q3: All five task silhouettes remain distinguishable.
Q4: No forbidden patterns appear.
Q5: The bounded sheet and shelf fit 393x852 with internal scroll.
Q6: Flip uses exactly two self-assess choices and Learning stays sequenced.
