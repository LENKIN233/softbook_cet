# Learning Interaction Candidate

## Candidate ID

lie-03

## Provenance

- Tool or model: model:codex
- Prompt: Remove the card frame and make the CET task a full-screen canvas with one bottom action.
- Source context pack: `docs/design/search-runs/2026-09-03-learning-interaction-evolution/context-pack.md`
- Artifact: No-render rationale: hard-filtered because the card ceases to be a physical progress object.
- Screenshots: No-render rationale: the product-truth violation is structural before rendering.

## Product Truth Fit

Reduces clutter and operation cost, but collapses the card and Space-continuity metaphor into a generic drill page.

## Focal Object

The full screen rather than a card.

## First-Read Path

Prompt -> options -> bottom action.

## Interaction Silhouette

Task silhouettes are clear but no longer belong to a persistent object.

## Spatial Model

Address becomes ordinary breadcrumb chrome.

## State Language

Fast and minimal, with little sense of knowledge ownership.

## Motion Causality

Page content replaces in place; no physical card transition remains.

## Platform Strategy

Responsive but indistinguishable from standard test-prep applications.

## Implementation Mapping

Would flatten `LearningSurface` into route content and discard accepted object mapping.

## Known Risks

Direct violation of the all-cards-physically-exist product commitment.

## Design Review Checklist Answers

Q1: One accent is possible.
Q2: The task is focal but the card is absent.
Q3: Silhouettes remain but lose object continuity.
Q4: No visual forbidden pattern is required.
Q5: Containment is strong.
Q6: Flip can remain two-state, but Learning loses its core metaphor.
