# Learning Interaction Evolution Promotion

## Promoted Artifact

`docs/design/decisions/learning-interaction-evolution-v1.md` and `docs/design/mocks/learning-interaction-evolution-v1.html`.

## Winning Candidate

Mutated `lie-08`, named Quiet Object Theatre.

## Baseline Comparison

The winner keeps the current card's stable address and action anchors but replaces the 92%-height white slab with a fixed atmospheric stage plus an intrinsically sized material sheet. Peek becomes the lightweight address aperture, hint becomes the only conditional task-plane handle, full long content scrolls inside the sheet, and answer/analysis resolve in the same object. It beats `learning-card-rhythm-v1` on focal clarity, perceived density, and state continuity without weakening interaction contracts or accessibility targets.

## Borrowed Fragments

- From `lie-02`: strict prompt-to-action hierarchy and anchored action rail.
- From `lie-04`: next-card edge visible only during settle/continue.
- From `lie-08`: stable stage, intrinsic sheet, contextual disclosure, and in-place resolve.

## Rejected Fragments

Giant white slab, always-visible utility row, control halo, gesture-only support, full-screen generic exam canvas, persistent stack, and separate result report.

## Rendered Proof

`rendered-proof.html#lie-08` and `candidate-proofs/survivor-comparison.html#lie-08`.

## Implementation Mapping Expectations

Future RN work maps the current card container to an atmospheric stable stage; prompt, front support, interaction, hint, correctness, and analysis map to one intrinsic material sheet; submit/self-assess/continue map to one action rail; favorite maps to one quiet tag; peek maps to the address aperture; hint maps to the conditional edge handle. The five task bodies remain separate components or branches.

## Unimplemented Gaps

No RN implementation is included. Real-device VoiceOver/TalkBack order, haptics, Reduce Motion, long-option scroll, keyboard/focus behavior, tablet layout, and PC-Web pointer sizing remain implementation evidence obligations.

## Failure Sedimentation

Add the persistent failure “fixed giant white slab mistaken for stable card” and “multiple visible disclosure controls” to `docs/design/rejected/learning-interaction-evolution-failures-v1.md`. Existing metadata, dashboard, and gesture-only guards remain applicable.

Q1: The current library owns the only strong accent on the stage and primary action.
Q2: The compact material sheet is focal; the read path is task -> interaction -> action -> in-place result.
Q3: The proof contains flip, choice, lock, elimination, and swipe silhouettes inside the same stable stage.
Q4: No gradient text, reward chrome, full-width bottom bar, serif, or four-state self-assessment appears.
Q5: The 393x852 proof keeps stage, sheet, 48dp handle, action rail, and floating navigation contained.
