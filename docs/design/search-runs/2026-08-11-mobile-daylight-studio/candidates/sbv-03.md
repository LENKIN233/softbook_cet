## Product Truth Fit

Preserves task priority, CET copy, and dedicated phone/tablet/desktop layouts. Risk: blue owns both brand and current collection.

## Focal Object

The elevated white learning workspace.

## First-Read Path

Warm environment → question → options → blue action.

## Interaction Silhouette

Multiple choice remains 2×2; result would open inline rather than in a modal.

## Spatial Model

Space uses the same elevated workspace with visible nested holders.

## State Language

Blue communicates stable controls; semantic mint and amber stay independent.

## Motion Causality

Elevation changes only when a task is selected or resolved.

## Platform Strategy

Phone is stacked, tablet is a broad workspace, desktop adds a bounded side rail.

## Implementation Mapping

Maps to app chrome, LearningSurface, SpaceSurface, and route navigation after acceptance.

## Known Risks

Brand/current-hall ambiguity and a familiar education-app appearance.

## Design Review Checklist Answers

Q1: The white workspace is the focal object.
Q2: One blue action completes the task.
Q3: State includes text, icon, and border changes.
Q4: No dashboard density or paper metaphor.
Q5: Each device class has a distinct composition.
Q6: All interaction families keep separate silhouettes.
