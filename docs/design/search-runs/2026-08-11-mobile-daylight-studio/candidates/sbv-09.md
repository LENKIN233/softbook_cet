## Product Truth Fit

The system-sequenced CET task is first, browse is secondary, and Space keeps 馆 → 组 → 盒 → 卡. The proof's generic hall labels are placeholders bound to canonical index 1 and must resolve owner-defined names at implementation; they do not create a new taxonomy. Learning, Space, Statistics, Mine, auth, membership, favorite, sleep, audio, assessment, error-capable controls, and continuity are represented without making counters the product core.

## Focal Object

The white current-task surface with a single coral collection edge and action.

## First-Read Path

Stable brand → current CET source → progress → prompt → answer field → one enabled confirmation → inline result → continuation.

## Interaction Silhouette

The proof operates multiple choice and flip; the companion atlas freezes separate flip, 2×2 choice, vertical lock, strike elimination, and layered swipe silhouettes.

## Spatial Model

Space exposes current hall, knowledge group, active box, current card, sibling cards, favorite tag, and the in-box later-learning zone. Returning to Learning keeps the current task relationship.

## State Language

Violet is stable brand chrome; coral belongs only to the active task topic; correctness uses green with text; flip assessment is exactly mint “有把握” and amber “再回看”. Favorite, sleep, selection, and account state use text, geometry, and ARIA state in addition to color.

## Motion Causality

Only navigation, reveal, result expansion, sheet opening, and switch movement animate because user state changes. Reduced-motion removes transitions.

## Platform Strategy

Phone uses a floating bottom capsule and compact first-fold completion; tablet uses a wide single task canvas and left rail; desktop introduces a bounded contextual side region. Narrow-phone and safe-area rules prevent overflow.

## Implementation Mapping

After this design-only artifact is accepted and merged, a separate implementation PR must map app chrome, LearningSurface, SpaceSurface, Statistics, Mine/Auth, membership sheets, and shared tokens to RN/Web without inventing visual decisions.

## Known Risks

Coral must not spread beyond the current hall, the bottom capsule must remain above OS safe areas, and desktop contextual space must not become a dashboard. Native font metrics and IME states remain implementation-phase validation items.

## Design Review Checklist Answers

Q1: The current CET task is the sole dominant focal object; supporting progress and location remain subordinate.
Q2: One primary action is visible at each state: confirm, continue, reveal, or assess.
Q3: Selection, correctness, favorite, sleep, auth, and assessment use text/shape/state as well as color.
Q4: The direction avoids paper, glass, monochrome wireframes, posters, targets, dashboards, and universal capsules.
Q5: Phone, tablet, and desktop are composed separately with explicit overflow and safe-area rules.
Q6: AP-22 is preserved through Learning↔Space continuity; VL-AP-07/AP-23 keeps flip assessment at exactly mint “有把握” and amber “再回看”.
