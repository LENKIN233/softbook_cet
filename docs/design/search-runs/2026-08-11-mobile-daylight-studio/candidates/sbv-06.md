# Spatial Shelf

## Candidate ID

sbv-06

## Provenance

- Tool or model: structural sketch review.
- Prompt: make the knowledge shelf the global product shell.
- Source context pack: `context-pack.md`
- Artifact: No-render rationale: rejected because Space architecture dominates Learning.
- Screenshots: No-render rationale: the product-truth violation is structural, not a render defect.

## Product Truth Fit

Space is rich, but system-sequenced Learning is no longer the primary journey.

## Focal Object

The global shelf rather than the current learning card.

## First-Read Path

Topic → shelf → box precedes the required current task.

## Interaction Silhouette

Learning becomes a browse action.

## Spatial Model

Hierarchy is explicit but over-promoted to the global shell.

## State Language

Active shelf and box are labeled, not color-only.

## Motion Causality

Shelf traversal is state-caused but too prominent.

## Platform Strategy

Works on tablet, performs poorly on phone.

## Implementation Mapping

No mapping is authorized because the journey order is wrong.

## Known Risks

Space-first drift and increased decision burden.

## Design Review Checklist Answers

Q1: The wrong object is focal.
Q2: The user must browse before studying.
Q3: State language is explicit.
Q4: It violates Learning priority.
Q5: Phone fit is poor.
Q6: Interaction families remain possible but secondary.
