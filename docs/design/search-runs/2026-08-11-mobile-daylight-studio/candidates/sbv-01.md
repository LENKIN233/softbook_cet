## Product Truth Fit

Keeps the system-sequenced single CET card first and the four top-level routes bounded. Risk: it could be mistaken for a generic productivity app.

## Focal Object

The white 2×2 question surface.

## First-Read Path

Brand mark → current task → four options → blue confirmation action.

## Interaction Silhouette

Multiple choice remains a 2×2 answer field with one submit action.

## Spatial Model

Space would preserve 馆 → 组 → 盒 → 卡, but the blue shell does not clearly distinguish the current hall.

## State Language

Blue is both brand and action; mint and amber remain reserved for flip assessment.

## Motion Causality

Only route and answer-state changes cause short transitions.

## Platform Strategy

Phone stacks; tablet widens the task; desktop uses a left rail.

## Implementation Mapping

Maps to mobile shell, LearningSurface, top-level navigation, and SpaceSurface after design acceptance.

## Known Risks

Generic visual identity, weak current-hall ownership, and excessive coolness.

## Design Review Checklist Answers

Q1: The task is the only large focal object.
Q2: The primary action is confirmation.
Q3: State is not expressed by color alone.
Q4: No paper, dashboard, or gamified metaphor is used.
Q5: Phone, tablet, and desktop compositions are explicit.
Q6: It preserves the five interaction families and two-option flip assessment.
