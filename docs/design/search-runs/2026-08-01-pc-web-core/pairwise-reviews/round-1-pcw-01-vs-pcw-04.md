Cross-functional review covering product truth, task clarity, visual language, motion, physical-space continuity, implementation mapping, and accessible layout.

## Product Truth

Both preserve one current object and low-cost input. `pcw-01` also preserves physical continuity and the shared object grammar across non-Learning routes.

## Task Clarity

`pcw-04` is marginally faster for a single answer. `pcw-01` is clearer across answer, review, audio, and return-to-Space states because the context rail has a defined role.

## Space Or Interaction Fit

`pcw-04` has the crispest keyboard and interaction discipline. `pcw-01` has the stronger Space relationship and softer exam-prep identity.

## Visual System Fit

`pcw-01` uses material depth without overwhelming the content. `pcw-04` risks generic utility-console flatness.

## Implementation Mapping

Both map to accessible Web regions. `pcw-01` covers the complete route shell; `pcw-04` contributes focus order and shortcut treatment.

## Rationale

Choose `pcw-01`; borrow keyboard focus, discrete alternative actions, and minimal shortcut annotation from `pcw-04`.

## Borrowable Fragments

- `pcw-04`: stable focus order, single-line shortcuts, and reduced-motion discreteness.
- `pcw-01`: shared three-region grammar and Space continuity.

## Rejected Fragments

- `pcw-04`: command-console tone and shortcut density that could compete with the current card.
