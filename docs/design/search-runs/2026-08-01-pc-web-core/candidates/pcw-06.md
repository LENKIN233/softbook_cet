# PC Web Candidate: Study Grid

## Candidate ID

`pcw-06`

## Provenance

- Tool or model: Codex negative-direction composition.
- Prompt: Present several recommended cards simultaneously so the learner can choose what to study.
- Source context pack: `../context-pack.md`.
- Artifact: `candidate-proofs/pc-web-candidate-proof.html#pcw-06`.
- Screenshots: `candidate-proofs/pc-web-candidate-proof.html#pcw-06`.

## Product Truth Fit

Fails the system-sequenced single-card flow by making card and module selection the main task.

## Focal Object

No single focal object; six equal card tiles compete.

## First-Read Path

Scan grid -> compare modules -> choose card, which creates management burden.

## Interaction Silhouette

All interactions collapse into the same preview tile.

## Spatial Model

Cards appear detached from owning boxes and libraries.

## State Language

Favorite and completion become grid badges rather than attached or spatial states.

## Motion Causality

Hover lift is decorative and does not represent product state.

## Platform Strategy

Mistakes desktop width for permission to expose more primary choices.

## Implementation Mapping

Would require a module picker that the product contract forbids as the default entry.

## Known Risks

- Generic learning marketplace appearance.
- High decision burden.
- Loss of Space ownership.

## Design Review Checklist Answers

Q1: Multiple library colors become strong accents; fail.

Q2: No single focal object; fail.

Q3: Core silhouettes are absent; fail.

Q4: No specific forbidden token, but the composition is product-wrong.

Q5: Contained but not acceptable.

Q6: Module selection is the main path; rejected.
