# PC Web Candidate: Quiet Command Rail

## Candidate ID

`pcw-04`

## Provenance

- Tool or model: Codex constrained HTML composition.
- Prompt: Optimize the PC Web surface for keyboard and mouse while preserving one current card and treating shortcuts as quiet annotations.
- Source context pack: `../context-pack.md`.
- Artifact: `candidate-proofs/pc-web-candidate-proof.html#pcw-04`.
- Screenshots: `candidate-proofs/pc-web-candidate-proof.html#pcw-04`.

## Product Truth Fit

Preserves low-cost interaction and non-touch equivalence. It risks looking like a generic productivity console rather than a distinct CET preparation product.

## Focal Object

One compact current card with a decisive interaction plane.

## First-Read Path

Prompt -> primary operation -> short feedback -> single-line address -> route rail.

## Interaction Silhouette

Strong shape discipline for all five interactions; shortcut labels remain outside the action hit areas.

## Spatial Model

Space uses the same rail grammar but expands to tree / current box / inspector. The Learning surface shows only a compact address path.

## State Language

Feedback is restrained; no achievement or management state. Favorite and sleep are expressed only in Space or attached tools.

## Motion Causality

Movement follows focus and resolve; reduced motion can make every transition discrete without loss of meaning.

## Platform Strategy

Best PC keyboard fit of the set, with semantic shortcut hints and stable focus order.

## Implementation Mapping

Maps simply to accessible landmarks and keyboard actions, but needs richer material treatment to retain Softbook identity.

## Known Risks

- Can feel like an exam utility.
- Over-minimization may hide Space continuity and audio.
- Shortcut labels may become chrome noise.

## Design Review Checklist Answers

Q1: Coral is the active library's only strong accent.

Q2: The interaction plane is focal; rails and hints are lower weight.

Q3: Canonical silhouettes are explicit and unambiguous.

Q4: No forbidden pattern appears.

Q5: All controls remain within the reference viewport.

Q6: Learning remains sequential and Statistics remains a quiet ledger in the same grammar.
