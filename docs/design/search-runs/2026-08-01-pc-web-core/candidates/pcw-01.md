# PC Web Candidate: Focused Workbench

## Candidate ID

`pcw-01`

## Provenance

- Tool or model: Codex constrained HTML composition.
- Prompt: Center one addressed CET object between a persistent navigation rail and a bounded context rail; use desktop width to reduce burden, never to multiply primary tasks.
- Source context pack: `../context-pack.md`.
- Artifact: `candidate-proofs/pc-web-candidate-proof.html#pcw-01`.
- Screenshots: `candidate-proofs/pc-web-candidate-proof.html#pcw-01`.

## Product Truth Fit

Preserves system sequencing, one current card, four top-level routes, attached review state, and visible Space continuity. The main risk is making the rails feel like application chrome around an ordinary flashcard.

## Focal Object

One system-selected current card centered on a quiet workbench.

## First-Read Path

Current card -> interaction plane -> compact address and continuity rail -> left navigation.

## Interaction Silhouette

The center region changes shape per canonical interaction while the rails remain stable; the candidate proof shows the multiple-choice 2 x 2 silhouette.

## Spatial Model

The right rail exposes library / group / box / card as an address aperture. Space expands that hierarchy into the left tree, current box, and inspector composition.

## State Language

Correctness and review attach as a slip under the same object. Favorite is a tag. Sleep remains a location under the owning box.

## Motion Causality

Only object-caused transitions move: answer slip attaches after resolution, the Space tree expands after navigation, and cancelled swipe returns the same card to center.

## Platform Strategy

Bounded to PC Web at 1440 x 900. The composition implements the accepted left rail / center workbench / right context rail decision instead of scaling phone UI.

## Implementation Mapping

Maps to a Web app shell, route rail, current-object region, interaction-specific center plane, and contextual right rail. No component hierarchy is treated as product truth.

## Known Risks

- The rails may feel generic if the current object lacks material depth.
- Long explanations must remain attached and scroll within a bounded region.
- Keyboard hints must stay secondary.

## Design Review Checklist Answers

Q1: Coral is the active library's only strong accent.

Q2: The current card is the focal object; rails are lower contrast.

Q3: The candidate proves the multiple-choice 2 x 2 silhouette and reserves shape-level branches for the other four interactions.

Q4: No forbidden pattern appears.

Q5: Not a phone viewport; the 1440 x 900 frame is fully contained.

Q6: Learning stays system-sequenced and does not expose module selection.
