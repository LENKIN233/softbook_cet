# PC Web Candidate: Exam Folio Desk

## Candidate ID

`pcw-02`

## Provenance

- Tool or model: Codex constrained HTML composition.
- Prompt: Treat the current CET object as a trusted exam folio on a broad desk, with answer material unfolding from the same object.
- Source context pack: `../context-pack.md`.
- Artifact: `candidate-proofs/pc-web-candidate-proof.html#pcw-02`.
- Screenshots: `candidate-proofs/pc-web-candidate-proof.html#pcw-02`.

## Product Truth Fit

Strongly preserves examination trust and attached review state. It risks turning the product into a document reader and weakening the five interaction silhouettes.

## Focal Object

A wide exam folio with prompt and answer slip.

## First-Read Path

Folio title -> current prompt -> primary action -> folded answer slip -> quiet address tab.

## Interaction Silhouette

The folio can host canonical interaction shapes, but its horizontal paper metaphor may visually dominate them.

## Spatial Model

An address tab shows the owning library, group, and box; Space would open as a shelf beyond the desk rather than as a separate utility page.

## State Language

Resolution is a material slip attached to the folio. Favorite stays a corner tag; sleep is not represented in Learning.

## Motion Causality

The answer slip unfolds only after response; otherwise the screen is static to preserve the current object's authority.

## Platform Strategy

Uses desktop width for readable exam material and a persistent slim route rail.

## Implementation Mapping

Maps cleanly to semantic article, fieldset, and attached result region, but needs strong constraints to avoid generic document layout.

## Known Risks

- Paper metaphor can overpower the application identity.
- Interaction silhouettes can collapse into content blocks.
- Dense text may make the workbench feel heavier than phone.

## Design Review Checklist Answers

Q1: Coral is the active library's only strong accent.

Q2: The exam folio is focal; route and address chrome remain quiet.

Q3: Canonical silhouettes are supported but less distinct than `pcw-01`.

Q4: No gradient text, serif dependency, reward chrome, or full-width bottom bar.

Q5: The wide folio is bounded inside 1440 x 900.

Q6: Learning remains sequential; no module picker appears.
