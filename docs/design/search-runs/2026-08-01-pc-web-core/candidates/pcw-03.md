# PC Web Candidate: Spatial Observatory

## Candidate ID

`pcw-03`

## Provenance

- Tool or model: Codex constrained HTML composition.
- Prompt: Make the physical knowledge address continuously visible as a restrained shelf around the current object, using width to show ownership without enabling arbitrary organization.
- Source context pack: `../context-pack.md`.
- Artifact: `candidate-proofs/pc-web-candidate-proof.html#pcw-03`.
- Screenshots: `candidate-proofs/pc-web-candidate-proof.html#pcw-03`.

## Product Truth Fit

Best preserves Learning to Space continuity and physical hierarchy. It risks making spatial browsing compete with the current Learning task.

## Focal Object

The current card inside an open current-box frame.

## First-Read Path

Current card -> owning box edge -> primary interaction -> parent shelf -> navigation.

## Interaction Silhouette

The interaction remains centered, but the surrounding box frame can reduce silhouette contrast.

## Spatial Model

Library tree, group shelf, current box, and card are simultaneously legible. Favorite is a tag and sleep is an alcove under the same box.

## State Language

Location carries state: active card remains in the box, favorite attaches to it, and sleep moves it to a bounded alcove without changing ownership.

## Motion Causality

Space hierarchy expands only when the user steps back from the card; sleep/wake motion follows the card between two regions of the same box.

## Platform Strategy

Uses PC width to show one additional hierarchy level without turning the map into a table.

## Implementation Mapping

Maps well to Space and address continuity, but Learning needs a stronger focus boundary to avoid browsing-first behavior.

## Known Risks

- Space can become the first read on every route.
- More than one library color may gain visual weight.
- The current-card interaction may feel embedded in a map rather than guided.

## Design Review Checklist Answers

Q1: Coral is the active library's sole dominant accent; other libraries appear only as low-weight dots.

Q2: The current card remains focal, though the box frame is deliberately more visible than in other candidates.

Q3: The Space hierarchy silhouette is strongest; Learning silhouettes require careful containment.

Q4: No forbidden patterns appear.

Q5: The hierarchy is contained inside 1440 x 900 with no horizontal overflow.

Q6: Module selection is not primary, but spatial context is close to that boundary.
