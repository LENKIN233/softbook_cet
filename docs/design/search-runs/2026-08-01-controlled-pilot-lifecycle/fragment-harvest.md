# Controlled Pilot Lifecycle Fragment Harvest

## Source Run

`docs/design/search-runs/2026-08-01-controlled-pilot-lifecycle/`, generation one.

## Best Focal Object

`cpl-01`: the current knowledge card stays dominant while the pilot slip is visibly attached and subordinate.

## Best First-Read Path

`cpl-01`: fixed pilot identity -> current card -> attached start notice -> card operation.

## Best State Language

`cpl-02`: concise “已开始 / 至…结束” language, moved to Mine for the final synthesis instead of remaining as a global strip.

## Best Space Or Interaction Model

`cpl-05`: the fifth resolved card settles toward its existing Space address, explaining why Space matters with the user’s real object.

## Best Motion Causality

`cpl-05`: only a confirmed fifth event causes the settle transition; replayed or reconciled events do not repeat it.

## Best Platform Adaptation

`cpl-06`: a compact receipt scales cleanly on small phones and at enlarged text without creating a second page hierarchy.

## Risky But Useful Breakthrough

`cpl-05`’s spatial aperture is useful because it connects Learning to Space, but it becomes decorative if the card flies or rotates. Roll back to an instant settled state under reduced motion or interruption.

## Rejected Failure Patterns

Blocking start modals, entitlement dashboards, equal-action completion menus, and tutorial carousels are recorded in `docs/design/rejected/controlled-pilot-lifecycle-failures-v1.md`.

## Synthesis Inputs

Use `cpl-01` as the base, borrow the settled-card aperture from `cpl-05`, borrow the compact completion receipt from `cpl-06`, and confine the explicit time ledger from `cpl-02` to Mine.
