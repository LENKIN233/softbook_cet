# DesignCandidate: Quiet Status Strip

## Candidate ID

`cpl-02`

## Provenance

- Tool or model: Codex design search.
- Prompt: Express pilot start and remaining eligibility in the smallest persistent account strip.
- Source context pack: `docs/design/search-runs/2026-08-01-controlled-pilot-lifecycle/context-pack.md`
- Artifact: `docs/design/search-runs/2026-08-01-controlled-pilot-lifecycle/candidate-proofs/survivor-comparison.html#cpl-02`
- Screenshots: candidate-bound rendered evidence at the artifact anchor.

## Product Truth Fit

Keeps the fixed pilot identity and server time honest, but a persistent strip risks competing with Learning.

## Focal Object

The current card remains focal; the strip is a quiet top-edge status object.

## First-Read Path

Pilot strip -> current card -> interaction.

## Interaction Silhouette

Accepted single-card silhouette with detached status chrome.

## Spatial Model

No change to the compact Space address.

## State Language

“已开始 / 至…结束” with no ticking seconds or urgency color.

## Motion Causality

Static after bootstrap reconciliation; no countdown animation.

## Platform Strategy

Phone-only, single-line default with two-line enlarged-text fallback.

## Implementation Mapping

Maps to a future read-only entitlement summary, preferably in Mine.

## Known Risks

Detached global chrome can become a second focal object and encourage time checking.

## Design Review Checklist Answers

Q1: Status is neutral; library accent remains singular.

Q2: Card remains dominant, though seeing the strip first is a risk.

Q3: Card and Space silhouettes are unchanged.

Q4: No dashboard or reward treatment.

Q5: Contained at 393 x 852.

Q6: No self-assess change.
