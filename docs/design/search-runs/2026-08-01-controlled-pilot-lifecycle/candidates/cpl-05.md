# DesignCandidate: Settled Card Desk

## Candidate ID

`cpl-05`

## Provenance

- Tool or model: Codex design search.
- Prompt: Make the fifth confirmed card explain Space by visibly settling at its existing address.
- Source context pack: `docs/design/search-runs/2026-08-01-controlled-pilot-lifecycle/context-pack.md`
- Artifact: `docs/design/search-runs/2026-08-01-controlled-pilot-lifecycle/candidate-proofs/survivor-comparison.html#cpl-05`
- Screenshots: candidate-bound rendered evidence at the artifact anchor.

## Product Truth Fit

Strongly supports the round boundary and Space value without a tutorial. It must not imply that the user manually files the card.

## Focal Object

The just-completed card settling into its address aperture.

## First-Read Path

Completed card -> address aperture -> “这一轮已放好” -> continue.

## Interaction Silhouette

Resolve -> settle -> continue, inherited from the accepted Learning rhythm.

## Spatial Model

Shows current library / group / box / card continuity through one compact aperture, not a flat saved list.

## State Language

Settled means server-confirmed completion, not a score or reward.

## Motion Causality

Only the newly confirmed fifth event causes an 180–240ms move toward the address. Reduced motion switches instantly.

## Platform Strategy

Phone-only; aperture collapses vertically under enlarged text.

## Implementation Mapping

Maps to the future round-boundary surface and Space deep-link, never local card reordering.

## Known Risks

Overly theatrical motion could imply manual filing or make replay confusing.

## Design Review Checklist Answers

Q1: One active-library accent.

Q2: Completed card remains focal.

Q3: Explicit Learning-to-Space continuity.

Q4: No reward or dashboard chrome.

Q5: Contained at 393 x 852.

Q6: No self-assess change.
