# DesignCandidate: Attached Pilot Slip

## Candidate ID

`cpl-01`

## Provenance

- Tool or model: Codex design search.
- Prompt: Keep the first valid card dominant while making the fixed pilot identity and 120-hour start legible without acknowledgement.
- Source context pack: `docs/design/search-runs/2026-08-01-controlled-pilot-lifecycle/context-pack.md`
- Artifact: `docs/design/search-runs/2026-08-01-controlled-pilot-lifecycle/candidate-proofs/survivor-comparison.html#cpl-01`
- Screenshots: candidate-bound rendered evidence at the artifact anchor.

## Product Truth Fit

Preserves the server-triggered start semantics because the slip exists only after a valid card is ready. It does not add an action or calculate entitlement.

## Focal Object

The current knowledge card.

## First-Read Path

CET4 受控试点 identity -> current card -> attached “体验已开始” slip -> card operation.

## Interaction Silhouette

The accepted single-card silhouette; the slip is an attached state layer, not a card family.

## Spatial Model

The existing compact Space address remains below the operation.

## State Language

Neutral “体验已开始” language; exact time detail stays in Mine.

## Motion Causality

The slip settles 8–12 points into the card edge only after the first valid card is prepared. Reduced motion shows the final attached state immediately.

## Platform Strategy

Phone-only for iOS and Android; copy wraps within 393 points and remains subordinate under enlarged text.

## Implementation Mapping

Maps to a future Learning identity chip and attached notice region; it does not define service calls.

## Known Risks

The slip could crowd long card copy; reserve height and allow it to collapse after the first read.

## Design Review Checklist Answers

Q1: One active-library accent; pilot state is neutral.

Q2: Current card first, attached state second.

Q3: Existing card silhouette and compact address are preserved.

Q4: No modal, reward, dashboard, or fake payment.

Q5: Rendered at 393 x 852 with wrapping.

Q6: No self-assess mutation; mint/amber authority remains unchanged.
