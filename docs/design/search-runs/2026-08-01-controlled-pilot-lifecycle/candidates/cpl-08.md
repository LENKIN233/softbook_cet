# DesignCandidate: Guided Carousel

## Candidate ID

`cpl-08`

## Provenance

- Tool or model: Codex design search.
- Prompt: Teach pilot duration, five-card rounds, Space, and free access across swipeable pages.
- Source context pack: `docs/design/search-runs/2026-08-01-controlled-pilot-lifecycle/context-pack.md`
- Artifact: prose-only rejected record.
- Screenshots: No-render rationale: tutorial pagination violates the first-card immediacy and no-onboarding hard filters.

## Product Truth Fit

Fails because it delays Learning and turns simple states into required explanation.

## Focal Object

Tutorial illustration rather than the current card.

## First-Read Path

Four explanations -> skip/next -> Learning.

## Interaction Silhouette

Onboarding carousel rather than a learning operation.

## Spatial Model

Space is explained abstractly instead of through the user’s actual card location.

## State Language

Future promises replace current state.

## Motion Causality

Pagination motion explains no product-state change.

## Platform Strategy

Phone swipe pattern, invalid because it adds burden on both platforms.

## Implementation Mapping

No mapping; it invents a separate onboarding flow.

## Known Risks

Skip behavior, duplicated copy, accessibility ordering, and lower first-round completion.

## Design Review Checklist Answers

Q1: Illustrations could add competing color.

Q2: Wrong focal object.

Q3: Space continuity is absent.

Q4: Tutorial carousel is forbidden.

Q5: Not rendered after hard-filter rejection.

Q6: No self-assess change.
