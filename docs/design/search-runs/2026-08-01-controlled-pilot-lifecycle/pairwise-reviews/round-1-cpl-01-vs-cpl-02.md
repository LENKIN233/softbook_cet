# Pairwise Review: Attached Slip vs Status Strip

## Pair

- Candidate A: `cpl-01`
- Candidate B: `cpl-02`

## Reviewer Role

Product Truth / UX Task / Accessibility Layout.

## Winner

`cpl-01`

## Visual Evidence

Compared `candidate-proofs/survivor-comparison.html#cpl-01` with `candidate-proofs/survivor-comparison.html#cpl-02`.

## Product Truth

`cpl-01` better ties the start notice to the first valid card. `cpl-02` can look active before the card is ready and encourages persistent time checking.

## Task Clarity

`cpl-01` keeps the next task inside the card. `cpl-02` adds a detached first-read region.

## Space Or Interaction Fit

Both preserve the card silhouette; `cpl-01` more clearly behaves like an attached state layer.

## Visual System Fit

`cpl-01` has one focal object. `cpl-02` risks two stacked focal bars.

## Implementation Mapping

Both map cleanly, but `cpl-01` has a safer trigger boundary and `cpl-02`’s time ledger is better confined to Mine.

## Rationale

Promote the attached slip because it makes the server-triggered meaning visible without adding a destination or countdown.

## Borrowable Fragments

Borrow `cpl-02`’s concise start/end wording for Mine.

## Rejected Fragments

Reject a persistent global trial strip on Learning.
