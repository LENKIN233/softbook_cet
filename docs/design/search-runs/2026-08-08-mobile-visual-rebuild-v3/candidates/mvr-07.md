## Product Truth Fit

The question remains visible under its analysis, so the moment of understanding is causally clear and does not become a separate report page. Material translucency comes from tracing paper, ink overlap, and tape rather than rounded blurred glass. Space uses stacked sleeves to preserve hierarchy and object location.

## Focal Object

A square-edged tracing sheet clipped over a colored base card.

## First-Read Path

Question on the top sheet -> peel or reveal strip -> aligned answer overlay -> stitched navigation ribbon.

## Interaction Silhouette

Flip keeps one large sheet as the dominant object. The back overlays answer and analysis on the same coordinates and presents exactly two small assessment tabs below.

## Spatial Model

Space is a set of nested document sleeves: library folder -> group sleeve -> box pocket -> card sheet. The current sheet is half-drawn from its pocket, favorite is a removable corner tab, and sleep is a labeled back sleeve with a return action.

## State Language

Indigo base paper identifies the current library. Pencil-gray annotations stay subordinate. Mint and amber are confined to the two assessment tab markers. Favorite and sleep are physical attachments, not new content boxes.

## Motion Causality

Reveal pulls a tracing overlay across the same question. Space slides the same sheet into its address pocket. Reduced motion fades in the aligned overlay without changing position.

## Platform Strategy

Phone uses a single stack and bottom stitched ribbon. Tablet can place the source sheet beside the overlay while retaining alignment. PC web can show the folder stack in a side rail without becoming a file manager.

## Implementation Mapping

The base sheet maps to current-card content, the reveal strip to the primary action, and the tracing overlay to back analysis. Space folder, sleeve, pocket, sheet, favorite tab, and sleep sleeve map to existing hierarchy and operations.

## Known Risks

Transparency must preserve contrast under dynamic type. Tape and pencil marks can become decorative if repeated. The overlapping sheet edges need careful clipping and must not recreate glossy glass through blur.

## Hard Filter Disposition

Rejected in generation 1 after real rendering. It remains in the same paper-object family as several failed directions, leaves large inactive areas, uses a near-full-width ribbon navigation, and renders Space as nested panels more than a convincing place. Borrowable fragment: align the answer overlay to the original question so the reason for the change remains visible.
