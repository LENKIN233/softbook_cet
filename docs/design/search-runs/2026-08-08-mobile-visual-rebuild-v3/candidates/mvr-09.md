## Product Truth Fit

The system still hands the learner one current task. Architecture supplies containment and location without introducing free browsing: the occupied study bay is the Learning object, while the same bay has a legible address in the campus hierarchy. The candidate is `candidate_exploration`; it does not authorize implementation.

## Aesthetic Thesis

Warm campus architecture can make CET preparation feel credible and inhabited without looking like a textbook, document reader, or productivity dashboard. Thick structural edges, open thresholds, sun patches, and deliberately square furniture replace stacked white cards.

## Focal Object

An open study bay framed by a deep-green arch, with the current prompt placed directly on the inner wall rather than on a floating card.

## First-Read Path

Current task heading -> prompt inside the occupied bay -> floor-level primary threshold -> quiet address plaque -> four-door navigation.

## Interaction Silhouette

Flip uses one tall architectural opening. The front has one reveal threshold; the resolved state opens a lower analysis chamber inside the same bay and then exposes exactly two peer assessment steps. Other interaction families would replace the bay interior with a 2 x 2 desk field, vertical lock doors, strikeable seat rows, or a single top tile with labeled left/right exits.

## Spatial Model

Space becomes a campus section: Softbook library building -> ability wing -> current study room -> occupied card seat. Favorite is a small nameplate fixed to the seat. Sleep moves the seat token to a clearly connected quiet room and explains how waking returns it to the learning sequence.

## State Language

Softbook brand comes from a fixed stepped-sun mark, repeated three-bay rhythm, and warm limestone material; sun yellow and cool blue appear only as tiny signature details. The fixture-bound current collection retains its canonical coral family, using deep coral `#A63D32` on arches, thresholds, and address plaques as the screen's only dominant identity accent. Semantic feedback is separate: registered/correct uses pine with a check label, flip `再回看` uses amber with a circular-arrow label, error uses berry with recovery copy, and disabled controls use patterned neutral concrete. No brand or collection color substitutes for feedback.

## Motion Causality

Reveal raises an interior screen to expose the analysis chamber; Space pulls back through the same opening to show its parent room and wing. Reduced motion substitutes the interior state instantly while preserving the opening and focus order.

## Platform Strategy

Phone uses one occupied bay and a low floor action. Tablet portrait stacks the active room above a connected parent-wing plan; landscape uses a true courtyard workspace with Learning on one side and its parent hierarchy on the other, not a phone column beside a sidebar. Android uses a top back affordance and system-inset-aware floor; iOS retains native edge return behavior.

## Implementation Mapping

A future mapping could bind the bay interior to current-card content, the floor threshold to the one primary action, and the address plaque to Space continuity. The building, wing, room, seat, favorite plaque, and quiet room map only to existing Space concepts. This search record does not define component APIs.

## Known Risks

Arches can become decorative or culturally theme-park-like if repeated on every control. Large type may force the bay to scroll, so the action floor needs a sticky but non-covering fallback. The visual test must verify that the building metaphor still reads as CET study within five seconds.

## Review Disposition

- Status: `rejected_after_independent_rendered_review`.
- Blocker: the architectural frame becomes more memorable than the CET task, while the Space state returns to nested panels and compresses its card actions. The rendered phone triptych does not establish a brand system that remains recognizable after the architectural metaphor is removed.
- Borrowable fragment: none at direction level. The quiet address plaque may be reconsidered only as a low-weight continuity cue inside a later, independently authored system.
- Prohibited carry-over: arch-first composition, building-as-brand styling, and nested-room treatment.
