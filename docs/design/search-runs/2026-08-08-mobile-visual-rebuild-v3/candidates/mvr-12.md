## Product Truth Fit

The learner still handles one system-selected task; adjacent ribbon segments show only past/future continuity and never become a carousel or module picker. The result settles into the same measure before the next measure is available. This remains `candidate_exploration`.

## Aesthetic Thesis

Softbook can feel directed and alive through tempo, cropping, and continuous color rather than through cards or pages. A broad flexible ribbon, hard cut ends, and occasional rhythm ticks make progress causal without building a metric dashboard.

## Focal Object

One enlarged measure in a continuous diagonal ribbon, with the current multiple-choice prompt embedded into the band and four answer cuts below it.

## First-Read Path

Enlarged current measure -> 2 x 2 answer field -> inline resolved measure -> one forward pull -> clipped rhythm navigation.

## Interaction Silhouette

Multiple choice is the proof lead: a prompt band above four cut-out answer fields. The resolved state preserves the chosen cut and adds analysis before the forward pull becomes dominant. Flip would widen one measure with a reveal pull and two assessment end tabs; lock uses aligned beats; elimination breaks removable spans; swipe has one current segment with labeled directional catches.

## Spatial Model

Space is a wall of nested ribbon holders: collection reel -> skill run -> active loop -> current measure. The current measure is visibly threaded through its active loop. Favorite is a stitched marker on the measure; sleep parks the measure on a side loop still tethered to the original holder.

## State Language

Softbook brand comes from a fixed double-cut mark, alternating long-short rhythm, and characteristic diagonal crop; seafoam and yellow appear only in low-area origin ticks. The fixture-bound current collection retains its canonical rose family, using raspberry `#8D285C` on the current run and active loop as the only dominant identity hue. Semantic feedback is independent: correct uses deep spruce with a check word, incorrect uses wine with `本题未选中正确项`, flip `再回看` uses amber with a return mark, and disabled uses dashed stone. Collection color never means correctness.

## Motion Causality

Choosing an answer locks one cut into place and expands analysis along the same measure; `下一张` pulls the ribbon exactly one measure. Reduced motion swaps the measure state without travel. Space coils the same colored edge into its box loop.

## Platform Strategy

Phone uses a diagonal crop that preserves a one-column text measure and lower forward pull. Tablet portrait uses a vertical ribbon with analysis on a parallel return section; landscape becomes a wide continuous workstation where prompt, result, and address occupy consecutive measures while remaining one task. Neither tablet orientation adds a fixed navigation sidebar.

## Implementation Mapping

The enlarged measure maps to current content, answer cuts to option controls, resolved measure to inline result/analysis, and forward pull to the primary continuation. Reel, run, loop, measure, favorite marker, and side sleep loop map to existing Space semantics.

## Known Risks

The ribbon can imply free horizontal browsing, so non-current segments must remain non-interactive. Diagonal edges can waste width at 320 pixels or collide with large type. Rhythm ticks must not resemble a progress counter.

## Review Disposition

- Status: `rejected_after_independent_rendered_review`.
- Blocker: the seafoam environment competes with the rose current-collection identity, the saturated diagonal field lowers exam trust, and the concentric Space state reads like a game target rather than a physical knowledge hierarchy.
- Borrowable fragment: the result can settle before the continuation control gains dominance; this sequencing principle already belongs to the shared UX matrix and does not promote the ribbon styling.
- Prohibited carry-over: diagonal ribbon shell, target/reel Space, rhythm-counter marks, and two-color brand claim.

## Design Review Checklist Answers

Q1: The fixture-bound current collection retains its canonical rose family and owns raspberry on the active run; the fixed double-cut brand mark and semantic spruce/wine/amber remain explicitly separate, subordinate roles.

Q2: The current measure is focal; the squint path is prompt, answer field, inline result, forward pull, then navigation.

Q3: Multiple choice preserves prompt plus 2 x 2 options; the remaining families have measure-specific silhouettes, and Space nests reel, run, loop, and measure.

Q4: The direction rejects paper, books, maps, blueprints, folders, glass, capsules, black dashboards, orange editorial layout, generic neutral cards, progress dashboards, and module carousels.

Q5: Diagonal bands are clipped inside each 393 x 852 frame, controls remain at least 48 pixels high, and text fields grow vertically. Tablet uses consecutive working measures, not stretched phone cards.

Q6: Flip would show only `有把握` and `再回看`; Statistics numerals remain tabular, and adjacent ribbon measures never become a module picker.
