## Product Truth Fit

The current task and next action are extremely clear, and the system sequence is visible as a quiet measure rather than a dashboard. However, the instrument metaphor risks making the product feel technical and emotionally cold. The Space topology also needs hard scrutiny because connection lines can replace physical hierarchy with abstraction.

## Focal Object

A calibrated indigo study viewport set into a dark enamel instrument face.

## First-Read Path

Study viewport -> illuminated action key -> state scale -> left command rail.

## Interaction Silhouette

Flip remains a single large viewport. The back changes the viewport state rather than opening another page, with two assessment keys directly below.

## Spatial Model

Space is a routed instrument panel: library bus -> group channel -> box bay -> card cassette. The current cassette is physically seated in its bay, favorite is a small marker, and sleep is a muted standby bay.

## State Language

Indigo illumination denotes current library and active route. Mint and amber are confined to small assessment indicators. Favorite is a metal marker; sleep is standby with a visible wake key.

## Motion Causality

Reveal rotates an internal shutter in the viewport. Moving to Space traces the same active line into the cassette bay. Reduced motion switches the illuminated state without shutter movement.

## Platform Strategy

Phone uses a left command rail and one large viewport. Tablet can show the route panel alongside the viewport. PC web can expand the topology but must not turn it into a monitoring console.

## Implementation Mapping

The viewport maps to the current card, the illuminated key to the primary action, and the state scale to light progress. The Space route, bay, cassette, favorite marker, and standby bay map to existing hierarchy and state changes only.

## Known Risks

Dark enamel may reproduce the black-heavy perception already rejected by the product owner. Technical labels can erode warmth and exam trust. The route diagram can become a system dashboard, and small command keys may fail large-text adaptation.

## Hard Filter Disposition

Rejected in generation 1. The dark instrument face repeats the rejected black-heavy perception, the command language feels technical rather than supportive, and the Space route is more diagram than physical place. Borrowable fragment only: reuse one causal route from current task to current position, never the console styling.

## Design Review Checklist Answers

Q1: The fixture-bound current library, anonymized in the proof as `当前馆`, uses one indigo identity light; mint and amber appear only as small flip feedback indicators.

Q2: The viewport is first, the action key second, the scale third, and navigation last.

Q3: Flip retains one large object and two assessment keys; Space nests bus, channel, bay, and cassette.

Q4: The proof avoids gradient text, achievement systems, fixed full-width navigation, serif type, pure black or white surfaces, and extra assessment levels.

Q5: The 393 by 852 proof contains the command rail and action keys without horizontal overflow.

Q6: Flip exposes only 有把握 and 再回看, while the system decides the learning sequence.
