## Product Truth Fit

The oversized current object and single reveal control make the next step immediate. Solid color replaces gray glass while the current-library indigo remains the only identity accent. The physical rail ties Learning to Space without exposing a module browser.

## Focal Object

A large offset question block riding on an indigo index rail.

## First-Read Path

Question block -> high-contrast reveal block -> small utility marks -> four-stamp navigation.

## Interaction Silhouette

Flip is a dominant rectangular card with a clearly separate thumb action. Its back keeps the same block footprint, exposes analysis in a sliding insert, and offers exactly two assessments.

## Spatial Model

Space is a nested index board: library field -> group lane -> box block -> card slips. The current card protrudes from the active box; favorite is a corner punch and sleep is a lower parked lane.

## State Language

Indigo indicates current position, while warm cream and pale blue act as non-semantic base planes. Favorite is a punched corner. Sleep lowers the slip into a parked lane and mutes its edge without inventing another collection.

## Motion Causality

Reveal shifts the card block one grid unit to expose the analysis insert. Space reuses that movement by sliding the current slip into its box. Reduced motion uses an immediate grid-state substitution.

## Platform Strategy

Phone uses one-column offset blocks and a compact two-by-two navigation stamp. Tablet spreads the index board into two working columns. PC web can use the full rail horizontally while keeping the current object visually dominant.

## Implementation Mapping

Future Learning maps the question block, utility marks, reveal block, and attached analysis insert to current behavior regions. Future Space maps nested board, active box, card slips, favorite punch, and parked lane to existing state. This record does not authorize implementation.

## Known Risks

Saturated planes can become loud or youthful if more than one accent gains weight. Offset edges need strict clipping at narrow widths. The navigation stamp must remain legible and cannot become a novelty control.

## Hard Filter Disposition

Rejected in generation 1 after real rendering. The yellow field, heavy outlines, and offset shadows look inexpensive and toy-like; front and back retain excessive empty area, and the four navigation stamps compete with the primary action. Borrowable fragment only: an answer insert may move out of the same current object to explain reveal causality.
