## Product Truth Fit

The current question becomes unmistakable and the case metaphor gives Space visible containment. Yet the punchy block language risks turning exam preparation into a toy, and the four navigation slugs may compete with the primary action. It is included to test the maximum expressive boundary.

## Focal Object

A massive question slug pressed into a cream composing bed.

## First-Read Path

Question slug -> reveal lever -> attached answer slug -> navigation slugs.

## Interaction Silhouette

Flip uses one large rectangular slug. The back replaces its face with the answer and adds a lower analysis block plus exactly two assessment keys.

## Spatial Model

Space is a typesetter's case: library case -> group row -> box compartment -> card slug. The current slug is lifted above its compartment; favorite is a small corner stamp and sleep is a side galley, not a second library.

## State Language

Indigo ink identifies the current library. Mint and amber appear only on tiny assessment keys. Favorite is a star-shaped impression; sleep removes ink saturation and places the slug in the galley.

## Motion Causality

Reveal rotates the physical slug. Space lowers the same slug into its compartment. Reduced motion swaps faces and changes depth without rotation.

## Platform Strategy

Phone uses a stacked composing bed. Tablet expands the case to show more parent compartments. PC web can resemble a larger composing table but cannot expose free box reassignment.

## Implementation Mapping

The question slug, reveal lever, answer block, and assessment keys map to Learning regions. The case, row, compartment, current slug, favorite stamp, and sleep galley map to existing Space concepts and controls.

## Known Risks

The block palette can feel childish, decorative, or game-like. Very large type reduces tolerance for long Chinese prompts. The physical lever may imply a gesture the app cannot support consistently across platforms.

## Hard Filter Disposition

Rejected in generation 1. The loud blocks, heavy borders, and lever read as a toy or campaign graphic; long content tolerance is poor and navigation becomes another set of competing objects. Borrowable fragment only: returning the same study object to a visibly nested compartment is a useful Space continuity principle.

## Design Review Checklist Answers

Q1: The fixture-bound current library, anonymized in the proof as `当前馆`, owns the sole indigo identity accent; other planes are environmental base colors.

Q2: The question slug is the focal object, then the reveal lever or assessment, then navigation.

Q3: Flip preserves one dominant object and two back decisions; Space nests case, row, compartment, and slug.

Q4: There is no gradient title, reward chrome, fixed full-width bar, serif type, pure black or white primary surface, or four-level assessment.

Q5: The composing bed and slugs remain within the 393 by 852 phone proof.

Q6: The back shows exactly 有把握 and 再回看 and does not expose module choice.
