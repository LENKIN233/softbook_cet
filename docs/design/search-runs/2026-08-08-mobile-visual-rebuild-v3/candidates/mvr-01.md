## Product Truth Fit

The system sequence remains primary, the user operates one current card, and the card retains a visible but quiet address into Space. The manual metaphor supports exam trust without turning the app into a generic book reader. This direction deliberately replaces the rejected Aurora and uniform rounded-card implementation hypotheses; it remains exploration until a later authority change is explicitly approved.

## Focal Object

An ivory study folio held against a colored book-cloth binding.

## First-Read Path

Question folio -> bound reveal control -> quiet secondary marks -> fore-edge navigation.

## Interaction Silhouette

Flip keeps one large centered study object. The front ends in one reveal action; the back attaches the analysis to the same folio and exposes exactly two light self-assess decisions.

## Spatial Model

Space becomes a cabinet opened from the manual's address tab: current library shelf -> clue group -> active drawer -> contained cards. The current card is raised from its drawer, favorite is a small attached mark, and the sleep area is an alcove rather than a second collection.

## State Language

Indigo book cloth carries current-library identity. A mint dot means 有把握 and an amber dot means 再回看 on flip only. Favorite is a corner mark; sleep is a recessed alcove with an explicit return-to-flow action.

## Motion Causality

The front page turns around the stitched gutter to reveal the back; entering Space pulls the active drawer from the same colored address tab. Reduced motion uses a page-state crossfade without simulated rotation.

## Platform Strategy

Phone uses a narrow fore-edge index. Tablet can open the manual and cabinet side by side. PC web can retain the bound gutter as a stable left context rail without enlarging the phone composition.

## Implementation Mapping

The future Learning surface would map the folio to the current-card region, the gutter to progress and address continuity, and the reveal strip to the primary action zone. The future Space surface would map shelf, drawer, contained cards, favorite mark, and sleep alcove to existing product operations. No component API is authorized here.

## Known Risks

The book metaphor can become nostalgic decoration if cloth, stitching, and paper marks exceed their structural roles. Long analysis copy needs a contained expansion state. The right-edge navigation must retain comfortable touch width without narrowing the folio.

## Hard Filter Disposition

Rejected in generation 1. It structurally revives the already rejected editorial-paper family, preserves too much empty page area, and makes the edge index compete with the current task. Borrowable fragment only: bind the visible Space address to the same physical edge as the study object; do not reuse the manual skin or navigation.
