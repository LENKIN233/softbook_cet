## Product Truth Fit

A single weighty marker is handed to the learner, and one physical control changes its state. The marker's rail notch provides continuity into Space without exposing arbitrary rearrangement. It is an exploration of durable objecthood, not implementation authority.

## Aesthetic Thesis

Matte glaze, fired color, offset magnetic studs, and crisp shadow gaps can make knowledge feel durable without paper nostalgia or glass translucency. The product should feel like a modern campus studio tool rather than an appliance dashboard.

## Focal Object

One asymmetric glazed tile magnetically seated on a horizontal rail, carrying the current study prompt across its open face.

## First-Read Path

Glazed prompt face -> protruding reveal stud -> underside analysis ledge -> engraved address notch -> compact native navigation.

## Interaction Silhouette

Flip uses one large ceramic marker rotating to its analyzed face, then exactly two separate magnetic assessment studs. Multiple choice uses four loose tiles in a 2 x 2 rack; lock uses stacked numbered sliders; elimination removes thin magnetic bars from one field; swipe uses one top marker and two labeled docking bays.

## Spatial Model

Space is a studio wall: collection rack -> skill bay -> active tray -> current marker. The current marker protrudes from its tray and retains its Learning notch. Favorite is a small magnetic star stud. Sleep transfers the marker to a side rest rail whose label and return path make clear that it is paused, not deleted.

## State Language

Softbook brand comes from a fixed three-stud mark, offset rack notch, and matte porcelain finish; guava and warm sand remain tiny signature details. The fixture-bound current collection retains its canonical indigo family, using mineral cobalt `#174E93` on the marker edge and active tray as the only dominant identity hue. Semantic feedback stays separate: correct uses fir with a check engraving, flip `再回看` uses amber with a return glyph, failure uses burgundy with retry text, and disabled uses a dotted unglazed finish.

## Motion Causality

Reveal pivots only the current marker around its magnetic center; moving to Space seats the same marker into its tray. Reduced motion changes faces and depth instantly, preserving labels and focus.

## Platform Strategy

Phone places the marker high enough for content and the reveal stud in the lower thumb band. Tablet portrait uses a tall wall with active marker and parent tray in one continuous rack; landscape lets the rack extend laterally while a measured analysis ledge stays beside the marker. Android back and iOS edge return remain platform-native.

## Implementation Mapping

The marker face maps to current content, reveal stud to primary action, underside ledge to inline analysis, and notch to address continuity. Rack, bay, tray, marker, favorite stud, and rest rail map to existing Space semantics without drag-anywhere behavior.

## Known Risks

Heavy object styling can feel childish if the tile becomes too glossy or colorful. A rotating tile cannot be the sole carrier of meaning. Long analysis requires the ledge to expand without shrinking the original prompt into illegibility.

## Review Disposition

- Status: `rejected_after_independent_rendered_review`.
- Blocker: the large glazed tile behaves like another pale card with a material skin, leaves excessive unused area, and forces the Space hierarchy into progressively smaller frames. The object claim is stronger than its operational advantage.

- Prohibited carry-over: oversized tile, decorative studs, rotating-material claim, and frame-within-frame Space.
