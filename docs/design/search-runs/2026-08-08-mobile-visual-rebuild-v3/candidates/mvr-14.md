## Product Truth Fit

The current long-sentence operation occupies the largest terrace and has one unmistakable action. Flat signal shapes distinguish action, location, and feedback without reducing the product to neutral cards with a swapped accent. Space uses stepped containment rather than a flat list. This is `candidate_exploration` only.

## Aesthetic Thesis

Softbook can be confident and young through large matte color fields, hard diagonals, stepped rhythm, and compact Chinese typography. The system has no simulated paper, glass, metal, or fabric; visual causality comes from fields changing ownership and height.

## Focal Object

A large stepped green task terrace containing three adjustable long-sentence slots, cut directly into the field.

## First-Read Path

Task terrace and prompt -> active slot signal -> check step -> inline unlocked explanation -> corner-flag navigation.

## Interaction Silhouette

Lock is the proof lead: three horizontal slots ascend as one staircase, with solved rows physically settling into the base. Multiple choice is a 2 x 2 flag field; flip is one tall signal field with exactly two assessment flags after reveal; elimination uses a vertical candidate fence; swipe has one top slab between two labeled landing fields.

## Spatial Model

Space becomes a stepped commons: collection field -> skill terrace -> active court -> current marker. Each parent contains the next through visible elevation and boundary changes. Favorite is a small triangular flag attached to the current marker. Sleep moves it to a lower quiet court that retains a visible stair back to the original holder.

## State Language

Softbook brand comes from a fixed four-corner mark, a short-short-long field rhythm, and hard diagonal cropping; cobalt and lemon remain tiny mark details. The fixture-bound current collection retains its canonical coral family, using deep coral `#A83D32` on the dominant task terrace and current court as the only dominant identity hue. Semantic feedback is independent: unlocked/correct uses deep cyan with `已解开`, flip `再回看` uses amber with a return arrow, errors use oxblood with recovery copy, and disabled uses neutral diagonal hatching.

## Motion Causality

Each solved lock row settles one step downward; the final result opens a lower explanation terrace before continuation dominates. Entering Space pulls back through the same stepped court. Reduced motion changes elevation and labels without travel.

## Platform Strategy

Phone uses full-width edge-to-edge fields with safe internal gutters and a low action step. Tablet portrait turns the staircase into a stacked workspace with a visible parent court; landscape uses a broad three-zone terrace for task, result, and location, no navigation sidebar and no phone-shaped panel.

## Implementation Mapping

The task terrace maps to current content, slot signals to lock controls, check step to primary action, and lower explanation terrace to inline result. Library field, skill terrace, box court, marker, favorite flag, and quiet court map to existing Space behavior only.

## Known Risks

Bold color can feel like a campaign poster or children's product if typography becomes oversized and playful. The stepped geometry needs a strict semantic order for screen readers and a one-column fallback at maximum type. It must remain visibly distinct from Kinetic Index rather than becoming another offset-block skin.

## Review Disposition

- Status: `rejected_after_independent_rendered_review`.
- Blocker: the high-saturation poster field feels campaign-like and youthful, while hard diagonal crops spend useful height without improving CET comprehension. The styling also remains too close to the flat offset-block family to count as a durable brand reset.
- Borrowable fragment: the three lock rows preserve vertical progression, settled state, inline explanation, and a clearly transferred `下一张`; the Space proof also keeps hierarchy legible through containment and elevation. These fragments require complete visual re-expression in any later direction.
- Prohibited carry-over: poster palette, hard diagonal shell, oversized signal fields, and corner-flag navigation.
