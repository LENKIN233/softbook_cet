## Product Truth Fit

The current task remains a single operable object, but its identity comes from an interlaced field instead of paper or a rounded card. A card's woven edge persists into Space, making location legible without promoting collection management. The candidate remains `candidate_exploration`.

## Aesthetic Thesis

Interlacing expresses learning as structure gained through one small operation at a time. A coarse warm warp, one saturated library weft, exposed selvedges, and flat stitched controls create a recognizably tactile system without skeuomorphic stationery.

## Focal Object

A wide tensioned weave whose central open row contains the current word-choice question.

## First-Read Path

Open row and prompt -> full-width finishing shuttle -> attached analysis band -> selvedge address -> four woven navigation knots.

## Interaction Silhouette

Flip is a single tall woven field with one unfinished row. Reveal completes that row and exposes analysis as an attached cross-band, followed by exactly two equal assessment tabs. Multiple choice becomes four woven patches; lock becomes three adjustable warp lanes; elimination physically loosens selected strips; swipe uses one shuttle with always-visible labeled end stops.

## Spatial Model

Space is a textile wall: collection roll -> skill panel -> active pocket -> current swatch. The current swatch keeps the same edge pattern as Learning. Favorite is a stitched corner tag; sleep places the swatch in a breathable rest pocket connected to its original holder, never a second collection.

## State Language

Softbook brand comes from a fixed crossed-loop mark, asymmetric selvedge, and recurring over-under rhythm; turquoise and melon appear only in the tiny mark and edge signature. The fixture-bound current collection retains its canonical rose family, using mulberry `#7F2857` only on the dominant weft and current address. Semantic feedback is independent: correct/registered uses forest plus check stitch, flip `再回看` uses ochre plus loop stitch, error uses crimson plus broken-line label, and disabled uses crosshatched sand.

## Motion Causality

Reveal sends one shuttle across the unfinished row and leaves the analysis band in place; moving to Space rolls the field back just enough to show panel and pocket ownership. Reduced motion swaps the open row for the complete row without simulated weaving.

## Platform Strategy

Phone uses a vertical textile with a reachable finishing shuttle. Tablet portrait becomes a tall loom with parent panel and active field sharing width; landscape rotates the structural logic into a broad loom, keeping text in a bounded column while the address pocket remains adjacent. Platform chrome uses native spacing rather than imitating knots.

## Implementation Mapping

The tensioned field maps to current-card content, the shuttle to the primary action, the cross-band to inline analysis, and the selvedge to a quiet address. Roll, panel, pocket, swatch, favorite tag, and rest pocket map to existing Space state only.

## Known Risks

Texture can lower text contrast or feel craft-oriented rather than exam-focused. Repeated thread lines may create visual noise at 200% type. The material should remain structural and never animate continuously.
