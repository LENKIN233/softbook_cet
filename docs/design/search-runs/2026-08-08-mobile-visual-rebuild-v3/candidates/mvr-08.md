## Product Truth Fit

The current question is an unmistakable working object, while measured guides explain its location without exposing system internals. Space becomes a true nested plan and preserves limited user control. The warm desk base avoids the rejected black-gray perception while indigo still owns the current-library identity.

## Focal Object

A pinned indigo-and-paper study plan resting on a warm drafting board.

## First-Read Path

Pinned question plan -> lower reveal ruler -> quiet address coordinate -> corner navigation index.

## Interaction Silhouette

Flip uses one large pinned sheet, with the reveal action integrated into a ruler below. The back keeps the same sheet and attaches analysis as a measured lower panel with exactly two assessment controls.

## Spatial Model

Space is a nested floor plan: library room -> group bay -> current box table -> card rectangles. The current card is pinned inside its table; favorite is a corner flag and sleep is a shaded side room connected by a wake path.

## State Language

Indigo blueprint linework identifies the current library. Warm board and paper colors are environmental. Mint and amber appear only on the assessment controls. Favorite and sleep remain attached states with explicit physical placement.

## Motion Causality

Reveal slides the ruler to expose the analysis panel under the same pin points. Space pulls back from the sheet to the nested plan. Reduced motion uses a direct crop change and keeps coordinates stable.

## Platform Strategy

Phone uses a compact pinned plan and L-shaped corner index. Tablet can expose question and parent plan side by side. PC web can expand the drafting board while preserving one current sheet and bounded Space operations.

## Implementation Mapping

The pinned sheet, reveal ruler, address coordinate, and assessment panel map to current Learning regions. The nested plan, room, bay, table, card rectangle, favorite flag, and sleep room map to existing Space concepts without inventing drag-anywhere behavior.

## Known Risks

Grid lines can become visual noise, especially under large text. Drafting marks must not look like system metadata. The plan metaphor needs warm language so it does not feel like engineering software.

## Hard Filter Disposition

Rejected in generation 1. It collapses back into the desk-and-paper family, the drafting grid adds noise, the corner index is unfamiliar, and the floor plan feels like engineering software. Borrowable fragment only: nested boundaries can make parent and current Space levels visible without flattening them into a list.
