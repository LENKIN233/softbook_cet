allocates tablet task and context without merely scaling the phone surface.

proves full-library deep links, complete recovery states, or native focus order.

## Visual System Fit

spacing, and panels are below product quality. mvn-01 remains generic and weaker
on tablet.

## Implementation Mapping

mvn-08 adds pane-collapse and accessibility-order cost; mvn-01 is simpler. The
comparison authorizes no RN mapping.

## Rationale

Tablet allocation wins this narrow comparison, but mvn-08 remains P1 blocked
and contributes no reusable composition.

## Borrowable Fragments

No visual fragment is borrowed. The candidate-independent requirement is that
tablet context appears only when useful and never obscures the current task.

## Rejected Fragments

Reject mvn-08's exact purple line language, placeholder glyphs, browser-only
tablet finish, and any claim that responsive CSS equals native tablet quality.
