# Mobile Visual Rebuild V4 — Fragment Harvest

## Source Run

2026-08-08 mobile visual rebuild v4, rebuilt exact eight-document cohort. No
candidate advances. The observations below explain which product-level tests
were exposed by comparison; they are not synthesis ingredients or selections.

## Product Truth And Implementation Hypothesis

The single current task, canonical interaction meanings, truthful result and
recovery order, Space containment, and Auth continuity are `product_truth`.
Every sheet, band, pane, icon, color, motion, ordering, density, and responsive
ratio in the candidates is a rejected `implementation_hypothesis`. A later
architecture derives new geometry rather than redrawing one of these fragments.

## Best Focal Object

mvn-07 provides the quietest relative phone focal hierarchy in the failed
cohort. This is evidence that current-task dominance needs a hard test; no
hierarchy, band, order, or component shell transfers to the next architecture.

## Best Interaction Density And Body Scale

mvn-01 demonstrates that one tested 2 × 2 option state can remain readable at
the recorded browser size. It contributes no density, scale, palette, brand
treatment, geometry, or component shell; the next architecture must prove the
canonical silhouette independently, including its large-text exception.

## Best First-Read Path

mvn-05 most clearly exposes the importance of phone action reach in the failed
cohort, while its vertical layering can push confirmation below the first view.
The accepted six-step Learning rhythm remains the authority; no mvn-05 order or
action-region geometry transfers.

## Best State Language

The rebuilt shared behavior supplies the useful state rule: empty or incorrect
submission receives explicit local feedback; a committed result leaves one
strongest next action; flip alone exposes labeled mint `有把握` and amber
`再回看`. No candidate's exact palette is promoted.

## Best Space Or Interaction Model

The comparison shows that action ownership and Space containment need separate
hard tests. Neither mvn-05 nor mvn-07 contributes a model or layout. Their
representative Space paths are insufficient; the next synthesis must prove
every library deep link and complete pending/error/retry behavior.

## Best Motion Causality

No candidate contributes promotion-grade causal motion. Actual swipe dragging is
now truthful and has labeled button alternatives, but route, result, Auth, and
Space state changes still require a reviewed causal-motion artifact before any
motion fragment can be harvested.

## Best Platform Adaptation

mvn-08 is the narrow relative tablet result because it at least separates task
and context instead of stretching the phone. It contributes no rail, pane,
ratio, role, icon, spacing, or master-detail skeleton. The next tablet
architecture must independently prove conditional context and product-grade
adaptation.

## Risky But Useful Breakthrough

No candidate or named combination contributes a reusable skeleton. The only
harvest is a set of candidate-independent tests: the primary action is reachable
on phone, Space ownership is legible, tablet context appears only when it helps
the current task, and the four-choice/body rhythm remains readable. The next
architecture must derive new geometry from those tests and roll back if it
creates equal-weight panels, hides the current task, turns continuity into a
decorative spine, or copies one composition across platforms.

## Rejected Failure Patterns

Do not revive frosted glass, saturated concept palettes, black selected
capsules, fake device chrome, long decorative pins, serif novelty, full-screen
semantic fills, nested rounded panels, tiny gray copy, placeholder glyph icons,
or one composition copied across iOS, Android, and tablet. Do not treat browser
`speechSynthesis` as formal audio.

## Synthesis Inputs

The next exact proposal may use only:

1. the product requirement that the phone primary action remains reachable;
2. the product requirement that Space visually preserves ownership;
3. the platform requirement that tablet context is conditional rather than a
   stretched phone or permanent empty pane;
4. the canonical four-choice silhouette and readable body-text requirement;
5. the shared truthful empty/error/commit/next behavior and real swipe drag.

The named v4 candidates remain provenance for why these tests matter, not
templates to trace. Their container geometry, order, ratios, and visual rhythm
must not be copied into the new grayscale architecture.

It must newly design platform iconography and behavior, causal motion,
pending/error/retry states, full-library deep links, production-grade tablet
composition, and approved audio binding. This harvest creates no design authority.
